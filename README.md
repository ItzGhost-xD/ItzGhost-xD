# 🍎 Featured Project — FruitGuard

<div align="center">

### Computer vision for plant-disease identification — with a focus on what happens when high benchmark accuracy meets the real world.

[![Live App](https://img.shields.io/badge/Live_App-open-ec3399?style=for-the-badge&logo=vercel&logoColor=white)](https://fruitguard-zeta.vercel.app)
[![API](https://img.shields.io/badge/API-live-8347e0?style=for-the-badge&logo=fastapi&logoColor=white)](https://fruitguard-api.onrender.com/api/health)
[![Repo](https://img.shields.io/badge/Repository-GitHub-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/ItzGhost-xD/FruitGuard-passionproject-csPS)

</div>

FruitGuard started as a plant-disease classifier and turned into a research project about **machine-learning generalization**.

The project asks:

> **How accurately do computer-vision models trained on controlled PlantVillage images identify crop leaf diseases when evaluated on real-world images with different lighting, backgrounds, framing, and image quality?**

### What I built

- 🧠 **MobileNetV3-Small** transfer-learning classifier
- 🧪 **Scratch CNN** for comparison
- 🌱 **13,755 PlantVillage images** across 14 classes
- 🌍 **95-image PlantDoc OOD benchmark** across 10 compatible classes
- ⚡ **FastAPI + PyTorch** backend
- ⚛️ **React + Vite** frontend
- ☁️ Deployed with **Render + Vercel**

### The result that mattered

| Model | Controlled Test | Real-World OOD |
|---|---:|---:|
| MobileNetV3-Small | **100.00%** | **18.95%** |
| Scratch CNN | **82.06%** | **14.74%** |

The 100% score was not the end of the project — the 18.95% result was the important part.

It showed how easily a model can look excellent on a familiar dataset while struggling when the environment changes.
