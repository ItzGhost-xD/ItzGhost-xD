## Featured Project

<div align="center">

### 🦇 BatsyAPI

**A production-grade, real-time Discord Presence API — built solo, end to end.**

Serves live Discord status, activity, Spotify, and game data over REST and WebSocket, backed by Redis caching and MongoDB analytics, with full Swagger docs and an interactive dashboard.

</div>

- ⚡ **Dual interface** — REST endpoints and a WebSocket stream for live presence updates
- 🧠 **Redis** caching layer + **MongoDB** analytics store
- 📖 **Swagger UI** reference docs and a live interactive dashboard
- 🚀 **GitHub Actions** CI/CD, plus a webhook-based deploy endpoint
- ☁️ Deployed on an **Oracle Cloud** VM, fronted by **Cloudflare**
